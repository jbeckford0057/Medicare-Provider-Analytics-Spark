# Data Directory

This directory is used for local project data and generated outputs.

## Raw Data

The raw datasets used in this project are:

1. Medicare Physician & Other Practitioners by Provider and Service
2. Medicare Fee-for-Service Public Provider Enrollment

The raw source files are not committed to GitHub because of their size.

Expected local structure:

data/
  raw/
  processed/

## Processed Data

Processed and integrated datasets are generated by the Spark notebooks and scripts during execution.

Cloud-based project data will be stored in Amazon S3 as part of the AWS implementation.
